# Wedding Invite Showcase

Crea una página web en React usando Tailwind CSS con un diseño estrictamente 'mobile-first' (optimizado para pantallas de celular).

Requisitos de la interfaz:

En la parte superior, coloca un header elegante con el título exacto: "CATALOGO invitaciones digitales para bodas". Usa una tipografía moderna.

Debajo del título, diseña una galería en formato de lista vertical (una sola columna) para que se vea perfecto en celular, con márgenes laterales adecuados.

Cada elemento de la lista debe ser una tarjeta (card) minimalista, con bordes redondeados y sombras suaves.

Dentro de cada tarjeta, incluye un contenedor con la clase aspect-video (16:9). Dentro de ese contenedor, coloca una etiqueta <iframe> lista para usar.

Muy importante: En la etiqueta <iframe>, deja el atributo src con el valor exacto src="PEGAR_LINK_DE_DRIVE_AQUI" para que yo sepa exactamente dónde reemplazar con mi link. Asegúrate de que el iframe tenga w-full h-full border-0 y allow="autoplay".

Debajo del video en cada tarjeta, incluye un texto de ejemplo (ej: "Diseño Clásico") y un botón que diga "Elegir este diseño".
